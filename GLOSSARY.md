# Hubo

A desktop launcher where everything is reached from a single input, the Omnibox.

## Language

**Omnibox**:
The single text input through which everything in Hubo is accessed. There is no search/chat mode toggle; what is typed decides where it goes.
_Avoid_: Search bar, search box, command bar

**App**:
Anything launchable from Hubo, whether an AI or a utility.
_Avoid_: Plugin, tool, module

**Result**:
One row in the Results list, representing one App (or one App in a particular role, such as receiving a prompt).
_Avoid_: Suggestion, match, item

**Results list**:
The dropdown of Results beneath the Omnibox. It is hidden whenever the Omnibox is unfocused.
_Avoid_: Dropdown, suggestions, menu

**Pinned AI**:
The AI that receives a prompt by default; it appears first among the AIs shown for a prompt.
_Avoid_: Default AI

**Header**:
The strip at the top of the window holding icon controls such as the close button. Not the "Hubo" title.
_Avoid_: Title bar
